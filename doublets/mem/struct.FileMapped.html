Struct FileMapped 

pub struct FileMapped<T> { /* private fields */ }
Expand description

Memory-mapped file storage.

Elements are stored directly in a memory-mapped region backed by a file. The file is resized and remapped on each grow or shrink call. Data is synced to disk on drop.

The file is guaranteed to be at least 4 KiB (one page) to satisfy OS-level mmap requirements.

Growth through grow_filled, grow_zeroed, or grow_with preserves complete elements present when the file was opened and initializes only the new tail. Padding added on opening is initialized on first growth.
