pub struct Store<T: LinkReference, M: RawMem<Item = LinkPart<T>>, TS: UnitTree<T> = LinksSourcesRecursionlessSizeBalancedTree<T>, TT: UnitTree<T> = LinksTargetsRecursionlessSizeBalancedTree<T>, TU: UnitList<T> = UnusedLinks<T>> { /* private fields */ }
Expand description

A single-memory doublets store backed by a size-balanced search tree.

All link data and tree-index metadata are stored in one contiguous RawMem region. Use Store::new for default constants or Store::with_constants for custom ones.
