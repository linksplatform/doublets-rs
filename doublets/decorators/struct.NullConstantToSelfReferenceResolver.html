Struct NullConstantToSelfReferenceResolver 

Source 
pub struct NullConstantToSelfReferenceResolver<T: LinkReference, L: Doublets<T>> { /* private fields */ }
Expand description

Turns the null constant into a reference to the link being written, and makes a bare create produce a self-referential point.

Port of C# LinksNullConstantToSelfReferenceResolver.
