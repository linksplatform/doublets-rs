### Added
- Add `mem::Release` with a minimal unchecked release primitive and checked `release`/`release_with` operations for both memory layouts. Add `decorators::CheckedRelease` for release-only decorator stacks, with explicit live-address, reset-endpoint and incoming-index contracts.

### Changed
- Delegate compatibility deletion's optional endpoint reset to `NonNullContentsLinkDeletionResolver` over checked release, preserving original callback states, flow and return values. Already reset links no longer incur a redundant update. Incoming usages, split-index reclassification and address reuse remain supported.
