1//! A doublets graph database library for working with associative link structures.
2//!
3//! Doublets stores data as a graph of typed links, each represented as a triple
4//! `(index, source, target)`. Two store implementations are provided:
5//!
6//! - [`unit::Store`] — a single-memory store for smaller graphs.
7//! - [`split::Store`] — a two-memory (data + index) store that separates link
8//!   data from tree-index metadata for larger graphs.
9//!
10//! # Quick start
11//!
12//! ```rust,ignore
13//! use doublets::{unit, Doublets, DoubletsExt};
14//! use mem::FileMapped;
15//!
16//! let store = unit::Store::<u64, _>::new(FileMapped::from_path("db.links")?)?;
17//! ```
